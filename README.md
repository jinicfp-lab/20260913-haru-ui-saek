# 하루의 색

감정, 상황, 가능한 시간을 고르면 바로 실행할 수 있는 짧은 회복 루틴과 음악 검색어를 만들어주는 파스텔 감성 웹서비스입니다.

## 특징

- HTML, CSS, JavaScript만 사용
- 외부 API 없이 브라우저에서 바로 동작
- 감정, 상황, 시간 기반 루틴 생성
- 해야 할 일을 입력하면 루틴에 자동 반영
- YouTube, Spotify 음악 검색 링크 제공
- 체크리스트 진행률 표시
- 감정별 배경 컬러 변화
- 루틴 복사, 메모 저장, localStorage 기록 기능

## 실행

`index.html` 파일을 브라우저에서 열면 됩니다.
